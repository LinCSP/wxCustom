# Документация wxCustomization

Это пользовательская документация библиотеки wxCustomization. Она описывает установку, сборку, архитектуру, поддерживаемые стили, API виджетов и миграцию с нативных wxWidgets-контролов.

   - Синтаксис CSS/QSS
   - Селекторы
   - Псевдо-состояния
   - Поддерживаемые свойства
   - Sub-control'ы

   - Единицы измерения
5. [Каталог виджетов](widgets.md)
6. [API](api.md)
7. [Миграция с wxWidgets](migration.md)

## Внутренняя документация

Разработческая документация, планы и история изменений хранятся в каталоге `_doc/`:

- `_doc/tasks.md` — список задач.
